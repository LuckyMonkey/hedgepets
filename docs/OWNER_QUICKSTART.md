# Owner quick-start: changing HedgePets yourself

Written 2026-11-13 so you can take the woods (or anything) into your own hands. Everything here runs on this laptop.

## Open it

- **App menu → "HedgePets (Godot editor)"**: the project in Godot 4.7.2 with the HedgePets dock on the right.
  Terminal: `godot --editor --path ~/work/hedgepets`.
- **App menu → "HedgePets: play from the woods"**: the game, standing at the woods trailhead, debug coins on.
  Other places: `godot --path ~/work/hedgepets res://garden.tscn -- --start=woods:<place> --debug` with trailhead,
  fork, hollow, ridge, creek, oak, nursery, pond, cellar, pines. Or click a place on the dock's **Woods map**.
- The full tool list (dock, world editor, filmmaker, VS Code) is in `docs/DEV_ENVIRONMENT.md`.

## Where the woods come from

The woods are generated by code each time the game starts (the same every time: seeded), then cached:

| What | Where |
|---|---|
| Places and the trail graph (NODES, edges) | `scripts/garden/woods.gd` top (`NODES`), `_build_trails` |
| The land: hills, creek, the ground shader | `woods.gd` `_build_land`, `height()`; `shaders/woods_ground.gdshader` |
| Trees, bushes, logs, rocks, litter | `woods.gd` (`_build_*` steps listed in `_steps()` ~line 313) |
| The far land you see beyond (the 3D skybox) | `scripts/garden/distant_land.gd` (a 1:16 miniature), drawn by `scripts/garden/miniature_sky.gd` + `shaders/distant_sky.gdshader` |
| The neighbourhood behind the garden's fence (also a 3D skybox) | `scripts/garden/neighborhood.gd` |
| Rocks | `scripts/art/rock_factory.gd`, rock types in `data/rocks.json`; tune in `tools/rock_lab.tscn` (inspector); preview grid `tools/rock_shots.gd`; `docs/ROCKS.md`, `docs/ROCKS_SPEC.md` |

Change a number, press **F5** (or the dock's play buttons) and look. The woods cache rebuilds itself when the code
changes (it says "building live" once); `tools/compile_woods.gd` makes the fast compiled copy again.

**Moving things by hand:** `godot --path . res://world_editor.tscn` (`docs/WORLD_EDITOR.md`): drag, turn, scale,
hide, Ctrl+S. For the woods, add a place after the `--`: `godot --path . res://world_editor.tscn -- --woods=ridge`.
Woods edits are kept in `world/woods_overrides.tres`, separate from the garden file, and survive a rebuild.

## Ship it

```
cd ~/work/hedgepets
git add -A && git commit -m "what I changed"
git push origin HEAD:main
tools/deploy_web.sh          # bakes, compiles the woods, exports, uploads to go.fridge.run/hedgepets (~5 min)
```

The deploy needs `ssh fridge` (set up) and a private X server for the woods compile - it finds the copy in
`~/work/xvfb-local` by itself (the laptop has no system xvfb and installing one needs sudo).

## Looking without a window

Captures of fixed views (to compare before/after): `docs/VISUAL_REGRESSION.md`. On this laptop use the private X
server:

```
X=~/work/xvfb-local/root; export LD_LIBRARY_PATH=$X/usr/lib/x86_64-linux-gnu
$X/usr/bin/Xvfb :77 -screen 0 540x960x24 -nolisten tcp & XP=$!; sleep 3
DISPLAY=:77 GOLDEN_OUT=~/work/shots GOLDEN_ONLY=garden_street,woods_ridge godot --path . --audio-driver Dummy \
  --rendering-driver opengl3 --resolution 540x960 --fixed-fps 60 --disable-vsync --script tools/golden_capture.gd
kill $XP
```

## Weather

The fog is the weather of the day (`garden.gd` `weather()`, `fog_at()`): mostly clear, sometimes haze, now and then a
misty day, plus a morning mist that lifts by noon. Force one with `HEDGEPETS_WEATHER=clear|haze|mist`.
